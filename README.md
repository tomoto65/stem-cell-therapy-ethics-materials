# 干细胞治疗伦理资料包

围绕三个干细胞治疗伦理议题整理的中文课程资料，包含选题背景、典型案例、伦理冲突、论文与下载地址、报道截图、中文重点标注和视频。

## 三个选题

1. **商业干细胞疗法与患者保护**：围绕未经证实的商业干预，讨论患者自主、不伤害、营销责任和监管。
2. **胚胎干细胞治疗与生命伦理**：以胰岛细胞替代治疗为案例，讨论胚胎道德地位、捐赠同意和风险收益。
3. **造血干细胞基因治疗与公平可及**：以镰状细胞病为案例，讨论治疗费用、机会分配、知情同意和长期照护。
